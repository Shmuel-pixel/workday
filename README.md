# workday

Shmuel's Workday: a home-screen app for organizing the workday at Five Star Services.

Live at https://shmuel-pixel.github.io/workday/

- `index.html` is the whole app (To-Do/Done board, Hebrew-English calendar, log, dumpsters, tools).
- `sw.js` saves the app on the phone so it runs offline.
- `manifest.webmanifest` and `icons/` make it installable with Add to Home Screen.
